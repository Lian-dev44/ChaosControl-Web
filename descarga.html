Compatibilidad estimada

Requisitos del sistema.

Estos valores son una base razonable para la versión actual. El rendimiento puede variar según la cantidad de procesos y conexiones del equipo.

Mínimos

Para ejecutar y monitorear

  • Sistema operativoWindows 10 u 11 de 64 bits.
  • ProcesadorCPU moderna de 2 núcleos.
  • Memoria4 GB de RAM.
  • AlmacenamientoEspacio suficiente para la carpeta del programa y sus recursos.
  • RedAdaptador de red compatible con Windows y conexión activa.
Recomendados

Para una experiencia fluida

  • Sistema operativoWindows 11 de 64 bits actualizado.
  • ProcesadorCPU moderna de 4 núcleos o más.
  • Memoria8 GB de RAM o más.
  • PantallaResolución de 1366 × 768 o superior.
  • PermisosCuenta con acceso de administrador para captura, límites y bloqueo por proceso.

Ejecución básica

Listo en cuatro pasos.

La distribución del programa usa una carpeta para conservar estables Qt Multimedia, los recursos gráficos y el reproductor.

Descarga

Obtén el paquete oficial de Chaos Control directamente desde GitHub Releases.

Extrae

Descomprime el paquete y conserva juntos el ejecutable y la carpeta de recursos.

Ejecuta

Abre ChaosControl.exe. Windows puede mostrar un aviso por tratarse de un proyecto académico.

Eleva si hace falta

Usa “Ejecutar como administrador” para activar la captura con WinDivert y controlar la red por proceso.

Antes de usar

Permisos claros, control responsable.

La inspección básica funciona con permisos normales. Windows puede limitar el acceso a procesos protegidos; ejecutar como administrador mejora la visibilidad y permite activar las funciones de captura y control por proceso.

!
Captura por proceso con WinDivert

Cuando está activa, el Panel muestra su estado y porcentaje de cobertura. Configura primero la velocidad del enlace para que el limitador calcule correctamente el porcentaje.
